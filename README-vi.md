## Khởi động nhanh 🚀

### Cách 1: Gói tích hợp (khuyên dùng)
> Link tải: [https://cutagent.online/](https://cutagent.online/)

Hãy tải gói tích hợp tương ứng với hệ điều hành và giải nén đầy đủ; không di chuyển riêng lẻ các thư mục `NarratoAI`, `runtime` hoặc `tools` bên trong. Windows dùng bản x64; macOS dùng bản arm64 cho Apple Silicon (M1/M2/M3/M4).

#### Windows

1. Mở thư mục `NarratoAI-windows-x64` sau khi giải nén.
2. Nhấp đúp `update-windows.bat` để cập nhật dự án, chờ đến khi cửa sổ báo cập nhật xong.
3. Nhấp đúp `start.bat` để khởi động ứng dụng và giữ cửa sổ này mở.
4. Mở trình duyệt và truy cập `http://127.0.0.1:8501`.

#### macOS (Apple Silicon)

1. Mở thư mục `NarratoAI-macos-arm64` sau khi giải nén.
2. Nếu hệ thống chặn mở script, hãy chạy lệnh sau trong Terminal (thay đường dẫn bằng vị trí giải nén thực tế):

   ```bash
   xattr -cr "/path/to/NarratoAI-macos-arm64"
   chmod +x "/path/to/NarratoAI-macos-arm64/"*.command
   ```

3. Nhấp đúp `update-macos.command` để cập nhật dự án, chờ đến khi cập nhật xong.
4. Nhấp đúp `start-macos.command` để khởi động ứng dụng và giữ cửa sổ Terminal mở.
5. Mở trình duyệt và truy cập `http://127.0.0.1:8501`.

### Cách 2: Triển khai bằng Docker (khuyên dùng cho macOS)
```bash
# 1. Clone dự án
git clone https://github.com/linyqh/NarratoAI.git
cd NarratoAI

# 2. Triển khai bằng một lệnh
docker compose up -d

# 3. Truy cập ứng dụng
# Mở trình duyệt tại http://localhost:8501
```

### Cách 3: Chạy cục bộ
```bash
# 1. Clone dự án
git clone https://github.com/linyqh/NarratoAI.git
cd NarratoAI

# 2. Cài đặt phụ thuộc bằng uv
uv sync

# 3. Sao chép file cấu hình
cp config.example.toml config.toml

# 4. Sửa config.toml, điền API key của bạn

# 5. Khởi động ứng dụng
uv run streamlit run webui.py --server.maxUploadSize=2048

# 6. Truy cập ứng dụng
# Mở trình duyệt tại http://localhost:8501
```
